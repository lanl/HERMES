## Getting Started with HERMES from Source

In order to run HERMES you need to have the pixi environment set up. Pixi can be installed via:

```
curl -fsSL https://pixi.sh/install.sh | sh
```

Once pixi is installed, you can set up HERMES environments and backends using the following pixi commands.

Install HERMES environment
```
pixi install
```

Build HERMES backends
```
pixi install-backends
```
